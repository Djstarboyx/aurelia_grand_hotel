# Aurelia Grand Hotel

React + TypeScript + Vite + Tailwind CSS website project.

## Run locally

1. Install Node.js (LTS) from https://nodejs.org/
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed in the terminal.

## Build

Run `npm run build`. The production site is generated in `dist/`.

## Deploy

Push the entire project to GitHub, then import the repository at https://vercel.com/.
Vercel should detect Vite automatically. Build command: `npm run build`; output directory: `dist`.
